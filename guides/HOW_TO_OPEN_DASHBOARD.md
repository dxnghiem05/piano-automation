# How To Open The Piano Dashboard

## Open The Launcher Folder

1. Open Finder.
2. Press `Command + Shift + G`.
3. Paste this path:

```text
/Users/dustinnghiem/Claude/PianoDashboard
```

4. Press `Enter`.

## Start The Dashboard

Double-click:

```text
Start Piano Dashboard.command
```

This starts the website and opens:

```text
http://localhost:8000
```

Keep the Terminal window open while using the dashboard.

## Start The Cloudflare Link

Only do this after the dashboard is already running.

Double-click:

```text
Start Cloudflare Link.command
```

Cloudflare will print a public `trycloudflare.com` link in the Terminal window.

Keep that Terminal window open while using the public link.

## Quick Reminder

- `Start Piano Dashboard.command` = local website.
- `Start Cloudflare Link.command` = public link.
- Closing either Terminal window stops that service.
