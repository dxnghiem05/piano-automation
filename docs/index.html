Creator publishing dashboard

PianoClip

PianoClip is a private creator dashboard for organizing, reviewing, and publishing short-form piano performance clips owned by the app operator.

The app connects to TikTok only after the creator signs in and grants permission. It uses approved TikTok API access to read the creator's public video list when authorized and to support the creator's own publishing workflow.

Services

What PianoClip Provides

Clip Review

PianoClip helps the app operator review generated short-form piano clips before they are selected for publishing.

Publishing Queue

The dashboard organizes selected clips into a private publishing workflow so the creator can track what is waiting, scheduled, or already posted.

Performance Tracking

PianoClip stores local analytics such as views, likes, comments, publish time, captions, clip length, and platform status for the creator's own content strategy analysis.

Creator workflow

How The Web App Works

  1. The creator uploads piano performance videos that they own.
  2. PianoClip prepares short clips for review in a private dashboard.
  3. The creator chooses which clips should be published or tracked.
  4. When TikTok access is enabled, the creator signs in with TikTok and authorizes the requested scope before PianoClip reads the creator's public TikTok video list.
  5. Performance data is used by the creator to compare posting time, captions, content type, and cross-platform strategy.

TikTok access

Authorized Account Data Only

PianoClip is not a public social media platform. It is a private tool for the app operator's own piano clips. TikTok access is used only after authorization and only for the creator workflow described here.

The submitted TikTok scope, video.list, is used to read the authorized creator account's public TikTok videos for review, tracking, and cross-platform performance analysis.
